# 丽贝卡：最后一枪 / ONE MORE SHOT — V6

以《赛博朋克：边缘行者》第 10 集公司广场战斗为灵感的 2D 像素动作同人游戏。选择丽贝卡，用「铁胆」霰弹枪击破重锤装甲，再靠近互动处决；也可以操纵亚当·重锤，对战会移动、闪避和射击的 AI 丽贝卡。**两种模式都需要击败对手，没有计时生存胜利。**

An unofficial 2D pixel-art fan game with two playable roles: Rebecca against
Adam Smasher, or a manually controlled Smasher against AI Rebecca. Includes
telegraphed attacks, Sandevistan, destructible armor, a lower-level arena and
an interactive execution ending. Requires defeating the opponent to win.

- 推荐直接用现代浏览器打开 `丽贝卡-最后一枪-v6.html`。9 个脚本、5 张角色/场景 PNG 和字体均已内嵌，可单独复制，无需联网或安装。

## 丽贝卡模式操作

| 按键 | 功能 |
| --- | --- |
| A / D、← / → | 移动，带加速与刹停 |
| Space、W、↑ | 跳跃，越过地面冲击波 |
| Shift | 朝移动方向滑步闪避，短暂无敌 |
| J / 鼠标左键（可按住） | 普通霰弹，消耗 1 发 |
| K / 鼠标右键（可按住） | 重霰弹，消耗 2 发 |
| R | 换弹；空弹仓也会自动换弹 |
| Q / 1、2、3 | 循环切换攻击部位 / 直接选择躯干、导弹架、腿甲 |
| E / 点击「互动处决」 | 重锤跪倒后，在 105 像素内的地面上进行处决 |
| P / Esc | 暂停 / 继续 |
| Enter | 开始 / 重试 |
| M | 开关原创合成音效与节拍 |

射击自动朝向重锤，含空中目标。弹仓 6 发，换弹 1.35 秒，普通射击间隔 0.42 秒、重霰弹 0.8 秒。重霰弹没有足够弹药时会开始换弹。移动和闪避不受换弹限制。

## V6 互动处决与重锤模式

丽贝卡模式中，重锤装甲归零后先失能跪倒，等待玩家靠近。此时可以继续移动；在双方水平距离 **105 像素以内**、丽贝卡站在地面且跪倒动作就绪时，按 **E** 或点击「互动处决」。处决演出持续 **2.6 秒**，包含近距离开枪、义体失控、支撑失效、身体倒地与余震；动画完成后才记为胜利，再衔接露西通讯和月球彩蛋。不会在装甲归零时自动跳过互动。

开始菜单新增「亚当重锤 / 全武装接管」。该模式由玩家操纵重锤，丽贝卡由 AI 控制，会寻找射击距离、换弹、应对攻击预警、跳跃闪避和选择装甲部位。难度影响 AI 的反应、闪避与射击能力。每种武装有独立冷却，HUD 按钮显示就绪或剩余秒数，也支持直接点击。

| 重锤按键 | 功能 |
| --- | --- |
| A / D、← / → | 地面移动 |
| J / 鼠标左键 | 臂炮连射 |
| K / 鼠标右键 | 导弹齐射 |
| Space、W、↑ | 跃起下砸 |
| Shift | 义体冲刺 |
| Q | 斯安威斯坦高速连击 |
| R | 短时装甲防御 |
| P / Esc | 暂停 / 继续 |
| M | 开关声音 |

重锤模式击败 AI 丽贝卡即获胜，重锤装甲耗尽则失败。该模式采用自己的胜利结算，不播放露西通讯。两种模式的最高分独立保存，也与之前版本的纪录分开。手机可点击六项武装按钮操作。

V6 新增四姿态透明处决图集，完整生成提示词见 `assets/ART_DIRECTION_V6.md`。跪倒前有失衡、屈膝和双膝落定过渡；处决时在 0.65 秒开枪、1.86 秒触地，原创机械声与动作同步。

V6 验证完成：70 项战斗逻辑测试、29 项纯 Node DOM 控制层测试通过；18 张实际 Canvas 场景渲染覆盖处决、双模式与低动效。13 秒真实合成音频测试无削波。离线文件检查确认 9 个脚本、5 张 PNG、1 份字体已内嵌，全部历史入口与 V6 一致。报告和复现脚本在 `output/v6/`；这些检查不代替浏览器布局实测。

## V5 声音、后坐力与下层战场

重锤半血后进入一次5.4秒转场：蓄力1.15秒砸穿广场，镜头连续跟随坠落，在2.75秒落入下层混凝土空间，3.05秒开始义体启动，5.4秒恢复战斗。转场保护双方生命，暂停战斗计时、攻击与弹药消耗；落地分开站位并恢复闪避，接完整的首轮斯安威斯坦预警。下层背景永久保留到本局结束，混凝土地基保留下砸裂痕但不会再次塌成广场玻璃洞；重试从广场重新开始。

音效全部为原创Web Audio合成：伺服马达、机械锁扣、砸裂玻璃、下层落地回响、高速破空声；每次斯安威斯坦锁定前的0.32秒窗口内播放0.24秒三连提示。关键提示会压低背景节拍，总线压缩控制音量；按M或点“声音”开启/关闭。

普通与重霰弹增加枪身回缩、枪口上扬、身体后移、方向性镜头反馈和弹壳机械声。重霰弹后坐更强，命中时有短促停顿、金属接触闪光和钢甲共鸣。一发霰弹只触发一次主要命中反馈，避免多弹丸叠出过亮/过响的效果。低动效模式保留操作后坐力与攻击提示，减少镜头和转场运动。

下层背景为内置image_gen生成的原创场景，创作规格和完整提示词见 `assets/ART_DIRECTION_V5.md`；不是动画截图或原声采样。场景以终局坠入广场下方空间的意象改编，并非逐镜头复刻。

验证：`npm test`47项通过；离线音效13秒试听位于 `output/v5/audio-preview.wav`，实测无非有限采样或削波。测试渲染库压缩器直通，峰值报告反映未压缩混音。实际渲染预览与音效复现脚本见 `output/v5/`。

二阶段分成过载蓄能、装甲崩裂、义体启动三个视觉阶段；新增局部电弧、脊柱灯、装甲碎片与地面扩散弧。斯安威斯坦使用黄绿到青蓝、紫色的逐帧人形残影及定向速度线，真身保持不透明。预警蓝色虚线追踪、琥珀实线锁定，显示每次连击倒计时；冲刺保留完整路径，范围与碰撞判定一致。预警边界最后绘制，提示放到人物头部上方。低动效模式保留路径和状态，关闭残影与飞散碎片。伤害、速度、三次连击和反应时间不变。

## V4 新玩法

### 二阶段与斯安威斯坦

重锤装甲降到 **50%** 时，完成当前空中下砸后在地面进行一次 **5.4 秒**砸穿广场与变身转场。装甲出现破口、火焰与裸露线路，清除当时的敌方弹丸，再启用三次高速冲刺连击。每一击都有独立追踪、路径锁定和预警；后续预警最低 0.55 秒，锁定后可跳跃或闪避。连击后有明显反击硬直，之后二阶段会继续轮换使用。所有预设和基础武装都保留二阶段。

### 部位破坏

点击 Boss 血条下方按钮，或按 **Q / 1、2、3** 选择目标。弹丸实际命中所选部位才会削减对应装甲，同时削减 Boss 总生命。

| 部位 | 耐久 | 击破效果 |
| --- | --- | --- |
| 躯干 | Boss 总装甲 | 稳定输出，装甲归零后进入跪倒与互动处决 |
| 肩部导弹架 | 总装甲的 16% | 掉落导弹架残件，后续导弹齐射削弱为 1 枚 |
| 腿甲 | 总装甲的 20% | 显露义体活塞，之后每次硬直额外增加 0.65 秒（受速度参数缩放） |

已经击毁的部位会退出瞄准循环。各部位有独立百分比、瞄准框、破坏火花和掉落碎件。

### 丽贝卡进攻连招

- **SHIFT＋J：滑铲射击**。贴地闪避时开枪获得 **1.35 倍伤害**，仍消耗 1 发。
- **跳跃＋K：空中重霰弹**。获得 **1.5 倍伤害**，仍消耗 2 发；后坐力会短暂托起身体。
- **近距离 K：打断蓄力**。在 135 像素内命中可打断炮击、冲刺、导弹、起跳和斯安威斯坦的地面蓄力，创造反击窗口；打断冷却 4 秒。开场锁定和变身演出不能被打断。

连招伤害可以与落地硬直、完美闪避的反击加成叠加。

### 可破坏广场

广场划分为玻璃板。普通下砸造成一级裂纹，二阶段下砸造成两级；同一块累计三级后橙色预警 **1.15 秒**再塌陷。缺口会影响落脚，并截断经过的地面震荡波。可以跳跃或滑步跨过，掉落则损失一格生命，由牵引系统拉回安全位置；最后一格生命耗尽仍判负。

缺口持续 **7 秒**后投放应急光桥，8 秒后恢复完整玻璃。两端锚定地板保持可站立，避免安全区域被永久耗尽。

### 胜利演出

V6 中先由玩家靠近完成处决，再播放约 **17 秒**的后续演出：丽贝卡放低霰弹枪、露西三段加密通讯和月球彩蛋；重锤保持倒地终态。对白为本作原创架空结局，无原作配音。通讯演出开始 2.5 秒后可按 Enter 或点击「跳过演出」，结算可「重播结局通讯」，重播不会重复计分。重锤模式不播放此段结局。

## 战斗规则

1. 开场丽贝卡站在地面，重锤已在她正上方准备下砸。首击在所有难度下至少预警 **1.9 秒**，其中固定落点后至少留出 **0.65 秒**；标准首击预警 2.15 秒。玩家从开始就可移动、跳跃、闪避和射击。之后的下砸恢复屈膝起跳、追踪、锁定的完整动作。
2. 红框固定后再闪避，跳过向两侧扩散的冲击波。靠近落点及时闪避触发完美闪避。
3. 落地硬直时受到 **2.4 倍伤害**。完美闪避提供 **2.4 秒反击窗口**，下一次开火额外造成 **2.5 倍伤害**，两者可以叠加。
4. 弹丸需要实际命中，画面显示伤害、枪口火光、弹壳和装甲火花。过早朝高速移动目标开枪可能落空。
5. 重锤会轮换攻击；每次攻击结束都有装甲破绽。击败重锤才能通关，存活时间不会自动带来胜利。

## 新增攻击手段

| 攻击 | 预警与应对 |
| --- | --- |
| 锁定下砸 | 红色落点固定后侧向闪避，再跳过冲击波 |
| 瞄准炮击 | 有追踪、锁定的虚线瞄准线；锁定后跳跃或闪避，炮弹需要实际飞到玩家身上才会伤害 |
| 义体冲刺 | 地面箭头先显示冲刺路径；跳起越过危险区域或迎面闪避，冲刺后可反击 |
| 导弹齐射 | 3–5 枚错时导弹，带独立倒计时；落点之间有真实安全间隙 |
| 二连下砸 | 第一击后短暂蓄势，再次追踪下砸；继续移动，第二击后再集中反击 |
| 斯安威斯坦连击 | 50% 装甲以下启动二阶段；三次分别锁定路径的高速冲刺，跳跃或迎面闪避 |

完整武装中，标准模式在装甲低于 66% 后解锁齐射、低于 33% 后解锁二连下砸；高危更早使用齐射，噩梦从开场就能使用原有五种招式。关闭全武装保留普通下砸、炮击、冲刺和半血后的斯安威斯坦。贴身时重锤会先后跃拉开距离再使用远程武器。

## 调整重锤难度

开始菜单可选四档预设，点击「自定义参数」或右上角「难度」打开详细设置：

| 预设 | 丽贝卡生命 | 重锤装甲 | 攻击速度 | 预警时长 | 武装 / 医疗 |
| --- | --- | --- | --- | --- | --- |
| 剧情 | 5 | 2500 | 80% | 130% | 基础三招 / 每 18 秒补给 |
| 标准 | 4 | 4000 | 100% | 100% | 全武装 / 每 22 秒补给 |
| 高危 | 3 | 5250 | 115% | 85% | 更早齐射 / 无补给 |
| 噩梦 | 一击致命 | 6500 | 130% | 72% | 开场全武装 / 无补给 |

可单独设置重锤装甲 **1000–10000**、攻击速度 **65%–160%**、预警时长 **65%–160%**，并开关全武装。速度影响攻击间隔、冲刺及弹丸速度；预警越长，反应余量越大。生命和补给遵循所选预设。设置保存在当前浏览器；每组预设/自定义参数单独记录最高分。

战斗中打开难度设置会暂停。取消返回当前战斗；「应用并重新挑战」会按新设置重新开局。

声音默认关闭。FX 可减少镜头震动、闪光及命中停顿，并遵循系统减弱动态效果偏好。窗口失焦或切到其他标签自动暂停。
